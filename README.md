# Jennysloth

Chen-Ling Lin's personal website, built with Astro.

## Local development

```powershell
cd C:\Users\linch\Documents\jennysloth.com
npm install
npm run dev
```

Open `http://localhost:4321`.

## Verification

```powershell
npm run build
```

The production build is written to `dist/`. Pushing `main` deploys the site through GitHub Pages.
